# متجرنا — مشروع معرض أعمال

مشروع متجر إلكتروني تجريبي باللغة العربية، باتجاه RTL، باستخدام HTML وCSS وJavaScript فقط.

## الملفات
- `index.html`: الصفحة الرئيسية
- `products.html`: قائمة المنتجات مع البحث والترتيب
- `cart.html`: سلة مشتريات تدعم زيادة الكمية وتقليلها والحذف
- `style.css`: التصميم المتجاوب
- `script.js`: تفاعلات المتجر وتخزين السلة في `localStorage`

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت مكتبات.

## ملاحظات
هذا نموذج واجهة أمامية تعليمي/استعراضي. لا يتضمن خادمًا أو قاعدة بيانات أو دفعًا إلكترونيًا حقيقيًا. بيانات السلة محفوظة محليًا في المتصفح.
